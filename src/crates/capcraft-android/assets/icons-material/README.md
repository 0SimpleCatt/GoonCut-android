# Material Symbols

Filled UI icons of the CapCraft Android app, used where they sit closer to the look wanted than
the Lucide outlines in `../icons`: [Material Symbols](https://github.com/google/material-design-icons)
by Google, Apache License 2.0 (`LICENSE-material-symbols.txt`). Taken unmodified, the Outlined
style at weight 400, from the npm package `@material-symbols/svg-400` 0.23.0
(`outlined/<name>.svg`). The Android build turns each into Compose path data
(`MaterialIcons.<Name>`, see `android/app/build.gradle.kts`).
