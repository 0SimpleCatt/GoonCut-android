# Icons

UI icons of the CapCraft Android app: [Lucide](https://github.com/lucide-icons/lucide) icons, ISC
licence (`LICENSE-lucide.txt`), by Lucide Contributors (portions Cole Bemis, Feather). Taken
unmodified from the npm package `lucide-static` 1.49.0 (`icons/<name>.svg`) on 2026-10-15. The
Android build turns each into Compose path data (`LucideIcons.<Name>`, see
`android/app/build.gradle.kts`).
